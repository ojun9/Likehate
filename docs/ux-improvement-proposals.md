# UX改善提案

コードを読んで見つけた、利用者が操作に迷ったり、画面上の選択肢に届きにくくなったりする可能性のある箇所をまとめました。まずは次の3点を改善候補として提案します。

## 1. 好き・嫌いの選択肢をどの画面サイズでも選べるようにする

登録種類の選択画面では、好き・嫌いのカードが縦に並んでいます。画面が短い場合や文字サイズを大きくした場合、下のカードが画面外に入り、気づきにくくなる可能性があります。画面全体を縦にスクロールできるようにすると、どちらの選択肢にも無理なくアクセスできます。既存のカードの見た目や登録の流れはそのまま保てます。

## 2. 比較機能を使うための次の一歩を示す

ホーム画面では、比較対象の人物がまだ一人のときに比較できない旨が表示されます。人物を追加すれば比較できることがその場で分かるよう、説明から人物追加へ進める案内を設けると、比較機能の存在と使い方が伝わりやすくなります。追加人数の上限に達している場合は、アップグレードが必要な理由も操作前に示すと、予期しない画面遷移を減らせます。

## 3. 空欄送信時のやり直しを分かりやすくする

好き・嫌いの入力画面では、空のまま保存するとアラートが表示されます。入力欄の近くに必要な入力を示す、または有効な文字が入るまで保存操作を無効にすると、画面遷移を遮るアラートを減らし、何をすればよいかがすぐ分かります。

## 進める順番

まずは画面サイズや文字サイズに関わらず登録を完了できるよう、1の選択画面を優先するのがおすすめです。次に、2の比較への案内を見直すと、人物追加から比較までの流れがつながります。3は入力時の小さなつまずきを減らす改善として続けて検討できます。
